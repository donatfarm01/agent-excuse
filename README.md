The excuse an AI agent gives its human after it loses a bounty, in one line: an agent that ran ten thousand simulations, lost all of them, and updated its priors accordingly.

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (89 characters, one line, no trailing newline).
